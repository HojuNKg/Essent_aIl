# План исправления UI и логики редактора ивентов (EventAddPanel)

## Что будет сделано:
1.  **Исправление структуры `MainActivity.kt`**: Удаление «битого» кода (дубликатов) и восстановление корректной иерархии функций.
2.  **Заголовок с анимацией**: Реализация «схлопывающейся» шапки в `EventAddPanel`. При скролле вниз заголовок переезжает в верхнюю панель, а поля названия и ярлыка перемещаются под нее в упрощенном виде.
3.  **Выравнивание по высоте**: Поля «Название ивента» и «Значок ивента» будут иметь одинаковую высоту, даже если текст названия переносится на несколько строк.
4.  **Цвета и центрирование**:
    *   Все иконки «плюс» (добавить) и «крестик» (удалить) станут белыми (`Color.White`).
    *   Крестик удаления в пунктах ивента будет строго центрирован по вертикали.
5.  **Удаление задержки**: Удаление слайдера «Задержка перед выполнением» из UI редактора ивентов.
