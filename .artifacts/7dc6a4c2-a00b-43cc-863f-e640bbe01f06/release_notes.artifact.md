# Release v0.5.1 🚀

## What's New / Что нового в версии 0.5.1

* 🚀 **Обновление версии**: Повышены `versionName` до `"0.5.1"` и `versionCode` до `5`.
* 🤖 **Система Events**: Расширенные условия выполнения действий (время, заряд, датчики, запущенные приложения).
* 🎬 **Система Macros**: Запись и точное воспроизведение касаний и макросов.
* ✨ **Glyph Interface**: Полная интеграция управления подсветкой Nothing.
* 🎛 **Кастомизация UI**: Добавлены панели `Favorites` и `Control Panel`.

## 📦 Файлы релиза
* APK файл собран и готов: `app/build/outputs/apk/debug/EssentAI-0.5.1.apk`

## Инструкция по созданию релиза на GitHub:
1. Перейдите на страницу репозитория: [https://github.com/HojuNKg/Essent_aIl/releases](https://github.com/HojuNKg/Essent_aIl/releases)
2. Нажмите **Draft a new release**.
3. Выберите существующий тег **v0.5.1**.
4. Укажите заголовок: `Essent.aI v0.5.1`
5. Вставьте текст описания выше.
6. Прикрепите собранный APK файл (`EssentAI-0.5.1.apk`) из папки `app/build/outputs/apk/debug/`.
7. Нажмите **Publish release**.
