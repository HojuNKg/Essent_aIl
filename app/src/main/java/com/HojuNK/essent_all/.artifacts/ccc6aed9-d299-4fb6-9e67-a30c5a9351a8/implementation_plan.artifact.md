# Оптимизация загрузки и «эволюционирующий» интерфейс

Внедрение поэтапной загрузки приложения для устранения рывков (jank) и создания плавного, «Nothing-style» опыта при старте.

## Proposed Changes

### [Component Name] Core Loading & Navigation

#### [MODIFY] [MainActivity.kt](file:///C:/Users/Hoju_/essential-mapper/app/src/main/java/com/aiden/essentialmapper/MainActivity.kt)

1.  **Состояния загрузки:**
    *   Добавление `LoadingStage` (enum: `INITIAL`, `CORE_READY`, `TRANSITIONING`, `FULLY_LOADED`).
    *   Перенос загрузки списка приложений в `MainContent` с фоновым выполнением.
    *   Управление `pagerState.userScrollEnabled` в зависимости от стадии загрузки.

2.  **Анимация BottomBar:**
    *   Обновление `PillBottomNavigation` для поддержки «эволюции»:
        *   На стадии `CORE_READY`: Панель свернута до одной круглой кнопки `KEY` в центре.
        *   На стадии `TRANSITIONING`: Плавное перемещение кнопки `KEY` влево и появление (slide/fade) остальных 3 кнопок.
        *   На стадии `FULLY_LOADED`: Полноценная навигация с подписями.

3.  **Оптимизация экранов:**
    *   Передача списка приложений (`apps`) через параметры во все экраны, чтобы избежать повторных тяжелых вызовов `loadLaunchableApps`.
    *   Добавление плейсхолдеров для иконок в списках, пока `apps` еще подгружаются в фоне.

## Verification Plan

### Manual Verification
1.  **Холодный старт:** Убедиться, что приложение открывается быстро, показывая только одну кнопку внизу.
2.  **Анимация:** Проверить плавность перехода от одной кнопки к полной панели (ничего не должно прыгать).
3.  **Блокировка:** Убедиться, что до завершения анимации нельзя пролистнуть на другой экран.
4.  **Отзывчивость:** Проверить, что открытие меню выбора приложений в `ConfigScreen` не вызывает зависаний, если список уже загружен в фоне.
