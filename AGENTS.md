# Essent.aI / Проект ремаппера Essential Key

Этот файл содержит техническую информацию и инструкции для AI-агентов, помогающих в разработке проекта.

## Краткое описание
**Essent.aI** — это Android-приложение для Nothing Phone (3a) Lite, предназначенное для переназначения аппаратной кнопки **Essential Key** (scanCode 250). Приложение позволяет вешать на кнопку запуск приложений, системные действия, управление глифами Nothing и сложные макросы, срабатывающие по количеству нажатий (одинарное, двойное, тройное) или удержанию.

## Архитектура проекта
Проект построен на базе **Accessibility Service** для перехвата аппаратных событий и **Jetpack Compose** для интерфейса.

*   **`EssentialKeyService.kt`**: Ядро проекта. Accessibility-сервис, который перехватывает нажатия кнопки, считает «тапы», управляет оверлеями (панель управления, избранное) и выполняет действия (макросы, жесты, запуск приложений).
*   **`Config.kt`**: Слой данных. Использует Jetpack DataStore для сохранения настроек, макросов и правил. Содержит логику сериализации/десериализации (JSON).
*   **`MainActivity.kt`**: Весь UI приложения на Compose. Включает в себя экраны настройки кнопок (Key), правил (Events), макросов (Macros) и игр (Games).
*   **`ControlPanel.kt`**: Логика и UI кастомизируемой сетки управления (Control Panel).

## Технический стек
*   **Язык**: Kotlin (Coroutines, Flows).
*   **SDK**: minSdk 33, targetSdk 36.
*   **UI**: Jetpack Compose (Material 3).
*   **Хранение**: DataStore (Preferences).
*   **Специфичные API**: 
    *   `AccessibilityService` (фильтрация KeyEvent по scanCode 250).
    *   `Nothing Ketchum SDK` (glyph-matrix-sdk-2.0.aar) для управления подсветкой Nothing.
    *   `SensorManager` (датчики света и акселерометр для условий в Events).
    *   `Camera2` для управления фонариком.

## Текущее состояние
Проект значительно расширен относительно базового форка:
*   Реализована система **Events** (Ивентов): выполнение действий при соблюдении условий (время, открытое приложение, заряд батареи, положение устройства в пространстве и т.д.).
*   Реализована система **Macros**: запись и воспроизведение последовательностей касаний, свайпов и задержек.
*   Интегрировано управление **Glyph Interface** для Nothing Phone.
*   Добавлены кастомные UI-панели: Favorites (барабан приложений) и Control Panel (сетка кнопок).

## Стиль кода
*   **Kotlin**: Использование идиоматичного кода, лаконичных выражений.
*   **Compose**: Стараться выносить сложные элементы в отдельные Composable-функции (хотя сейчас много кода сосредоточено в `MainActivity.kt`).
*   **Именование**: camelCase для функций/переменных, PascalCase для классов и Enum.
*   **Комментарии**: Краткие описания на русском/английском для ключевой логики (особенно в `Config.kt` и `EssentialKeyService.kt`).
